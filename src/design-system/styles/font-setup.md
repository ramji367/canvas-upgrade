# Satoshi font setup

Sift uses Satoshi through Fontshare's official webfont stylesheet. The ITF Free Font License does not permit redistributing the font binaries with this source library, so consumers should load the official stylesheet in their document head:

```html
<link rel="preconnect" href="https://api.fontshare.com">
<link rel="preconnect" href="https://cdn.fontshare.com" crossorigin>
<link rel="stylesheet" href="https://api.fontshare.com/v2/css?f[]=satoshi@300,400,500,700,900&display=swap">
```
